# SEMANTICS — Военный навигатор

## 1. Что это

Большой обзор поискового спроса по темам:

- новостройки;
- военная ипотека;
- квартиры / покупка по военной ипотеке;
- калькулятор военной ипотеки;
- Краснодар;
- Краснодарский край;
- Крым отдельно;
- брендовый слой `Военный навигатор`.

Дата сбора: **2026-06-05**  
Источник: **Yandex Wordstat API** через `mcp__yandex_searchapi.*`

## 2. Методика

- Регион `Краснодар`: `35`
- Регион `Краснодарский край`: `10995`
- Для Крыма использовались:
  - гео-фразы `крым`, `севастополь`, `симферополь`;
  - распределение спроса;
  - отдельные city-кластеры, потому что спрос в Крыму распадается по городам, а не только по общей формулировке региона.

Важно:

- Wordstat показывает родительские и вложенные формулировки одновременно.
- Поэтому суммы по нескольким фразам нельзя трактовать как “чистый рынок без дублей”.
- Для решений по архитектуре и страницам ориентируемся на:
  - головные запросы;
  - повторяющиеся паттерны;
  - устойчивые интенты;
  - прямые коммерческие формулировки.

## 3. Ключевые выводы

### 3.1. Краснодар и край

- Базовый коммерческий спрос по новостройкам сильный и устойчивый.
- Основная входная формулировка: **`новостройки краснодар`**.
- Для военной ипотеки спрос заметно меньше, но он реальный и стабильный.
- Самая важная развилка: люди **редко** ищут фразу `купить новостройку по военной ипотеке` буквально.
- Гораздо чаще ищут через более живые формулировки:
  - `военная ипотека краснодар`
  - `квартиры по военной ипотеке`
  - `ипотека краснодар новостройки`
  - `калькулятор военной ипотеки`
  - `условия`
  - `процент`
  - `сумма`

### 3.2. Краснодарский край

- Спрос “по краю” есть, но в реальности он распадается на городские и курортные кластеры.
- Внутри края по новостройкам дополнительно всплывают:
  - `новороссийск`
  - `анапа`
  - `сочи`
- Это значит, что “Краснодарский край” лучше использовать как **поддерживающий SEO-слой**, а не как единственную главную формулировку.

### 3.3. Крым

- В Крыму спрос по новостройкам сильнее, чем по военной ипотеке.
- Самый частый паттерн: **новостройки Крыма у моря / от застройщика / купить квартиру в Крыму в новостройке**.
- Военная ипотека в Крыму есть, но она заметно уже и чаще распадается на городские кластеры.
- Для Крыма уже сейчас видны отдельные самостоятельные точки спроса:
  - `новостройки севастополя`
  - `новостройки симферополя`
  - `военная ипотека севастополь`
  - `симферополь ипотека военным`

### 3.4. Калькулятор

- Да, **калькулятор реально ищут**.
- Это не маргинальный хвост, а полноценный отдельный интент.
- Для края прямой запрос `калькулятор военной ипотеки` даёт **273** показов в ядре.
- Значит, тему калькулятора нельзя прятать только в FAQ.

### 3.5. Бренд “Военный навигатор”

- Прямого брендового SEO-спроса по проекту пока **нет**.
- `военный навигатор` в Wordstat — это в основном шум вокруг устройств / навигации.
- Гео-брендовые формулировки вроде `военный навигатор краснодар` сейчас не формируют видимый спрос.

Вывод:

- стратегию нельзя строить на брендовых запросах;
- стратегию нужно строить на **объектных, ипотечных и проблемных интентах**.

## 11. Что люди действительно ищут

### Ищут

- **новостройки краснодар**
- **новостройки крыма**
- **военная ипотека краснодар**
- **военная ипотека в крыму**
- **квартиры по военной ипотеке**
- **ипотека краснодар новостройки**
- **калькулятор военной ипотеки**
- **условия, банки, процент, сумма**
- **новостройки севастополя / симферополя**

### Почти не ищут как literal-form

- `купить новостройку по военной ипотеке`
- `новостройки по военной ипотеке`
- `военный навигатор краснодар`
- `военный навигатор по новостройкам`

Вывод:

- SEO и архитектуру надо строить по живым формулировкам;
- буквальные маркетинговые формулы использовать внутри текста, но не делать на них ставку как на основной поисковый вход.

## 16. Рекомендации по архитектуре сайта

### Уже правильно

- держать сильную страницу по `военной ипотеке в Краснодаре`;
- держать отдельный крымский слой;
- не строить позиционирование только на бренде.

### Что стоит усилить

1. **Сохранить и усиливать страницу `/voennaya-ipoteka-krasnodar/`**  
   Это основной коммерческий SEO-вход по теме.

2. **Добавить / усилить отдельный слой под новостройки**  
   Варианты:
   - либо расширить текущую краснодарскую страницу так, чтобы она уверенно покрывала и `новостройки краснодар`;
   - либо позже сделать отдельную объектную страницу.

3. **Сделать отдельную страницу под калькулятор**
   - рабочее имя: `/kalkulyator-voennoy-ipoteki/`
   - даже если сначала это контентная страница без полноценного интерактивного калькулятора.

4. **Развивать Крым не одной общей страницей, а ступенчато**
   - сначала `/voennaya-ipoteka-krym/`
   - затем `/novostroyki-krym/`
   - затем при подтверждении ресурса и спроса:
     - `/novostroyki-sevastopol/`
     - `/novostroyki-simferopol/`

5. **Юридические и возраженческие кластеры вынести в FAQ / статьи**
   - развод;
   - продажа квартиры;
   - банки;
   - сумма;
   - семейная + военная ипотека;
   - СВО.
