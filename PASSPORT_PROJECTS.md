# PASSPORT_PROJECTS — Военный навигатор

## Что это

Клиентский Astro-проект АМС для сервиса `Военный навигатор`.

- Папка проекта: `C:\Users\User\Desktop\Сборка АМС\Военный навигатор (AMS)`
- Production: `https://voen-navigator.ru`
- Стек: Astro 5 + Tailwind CSS v4 + TypeScript strict + React islands
- Формы: AMS Leads API

## Источник правды

Канонический паспорт проекта лежит в:

- `project-docs/PASSPORT_PROJECTS.md`

Канонический журнал проекта лежит в:

- `project-docs/WORKLOG.md`

## Что читать первым

1. `PASSPORT_PROJECTS.md` — этот корневой роутер.
2. `project-docs/PASSPORT_PROJECTS.md`

5. `project-docs/DESIGN_SYSTEM.md`

Корневой файл нужен как обязательная точка входа по правилам АМС. Детальные правила, позиционирование, CTA, локальные ограничения и текущие решения ведутся в `project-docs/`.
