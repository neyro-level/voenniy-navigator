## 3. Rules fixed in code

- Каждая статья журнала имеет одну основную target money page на уровне системной архитектуры.
- Архив `/journal/` получил блок `Главные страницы по теме`.
- Рубрики журнала получили рекомендованную commercial page.
- `JournalCard` в архиве и рубриках теперь показывает явный `Следующий шаг`.
- `JournalPopular` теперь может выводить `Главный следующий шаг` на money page.
- На 5 priority commercial pages добавлен обратный блок `Полезные материалы`.
- Массовой ссылки на весь журнал подряд нет: каждый money page получает только свой supporting-кластер.
