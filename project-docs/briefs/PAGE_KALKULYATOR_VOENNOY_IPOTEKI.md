## 2. Семантика и главный интент

### Главный SEO-интент страницы

Дать пользователю понятный ориентир по сумме, накоплениям и логике расчёта по военной ипотеке.

### Главный коммерческий запрос (ядро H1)

`калькулятор военной ипотеки` / `рассчитать военную ипотеку`

### Сопутствующие запросы

- `калькулятор военной ипотеки онлайн`
- `сумма по военной ипотеке`
- `военная ипотека сколько`
- `калькулятор семейной военной ипотеки`
