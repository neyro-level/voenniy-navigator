## 6. As-built стандарт страницы

Эта страница принята как эталон для следующих внутренних страниц сайта по четырём слоям:

- **Фрейм:** секции живут в стандартном `vn-container`; калькулятор больше не использует отдельный oversized-контур шире общего сайта.
- **Типографика:** H1/H2/H3, lead, body и secondary-тексты выровнены под токены сайта из `global.css`, без локальной системы размеров для обычных заголовков и абзацев.
- **Ритм секций:** заголовочные зоны, ширина текстовых колонок и переходы между блоками собраны по паттерну главной страницы.
- **FAQ-паттерн:** для калькулятора используется shared-компонент `src/components/sections/FAQ.astro`; это канонический стандарт FAQ и для следующих страниц.

### Базовое правило по текстам для следующих страниц

- `Hero H1` — `var(--fs-display)`, line-height около `1.05-1.1`, без локальных oversized `px/clamp`.
- `Section H2` — `var(--fs-h2)`, единый ритм между блоками, без ручного разнобоя по breakpoint’ам.
- `H3 / card title` — `var(--fs-h3)`.
- `Lead` — `var(--fs-lead)` только для hero и финального CTA; обычные секционные вводные идут через `var(--fs-body)`.
- `Body` — `var(--fs-body)`.
- `Secondary / supportive text` — `var(--fs-body-sm)`.
- Исключения допускаются только для UI-чисел внутри калькулятора: summary values, range outputs и подобные служебные числовые акценты.
