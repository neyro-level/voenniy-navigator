# Journal Briefs

Здесь лежат рабочие брифы на статьи журнала Военного навигатора.

Главный вход:

- `project-docs/JOURNAL_EDITORIAL_MAP.md`

Порядок работы:

1. Сначала открыть `JOURNAL_EDITORIAL_MAP.md`.
2. Затем открыть нужный `ARTICLE_*.md`.
3. После правок статьи обновить сам бриф, если изменились смысл, интент, мета-слой или маршрутизация.
4. После завершения задачи зафиксировать изменения в `project-docs/WORKLOG.md`.
