## 2. Главный интент страницы

### 2.1. Роль страницы

Главная — сервисный hub, не личная страница Михаила. Её задача: объяснить, что Военный навигатор бесплатно помогает подобрать новостройку или дом по военной ипотеке, и дать быстрые входы в каталоги и инструменты.

### 2.2. Главный SEO-интент

Сервис подбора новостроек / домов по военной ипотеке, бесплатно для военных.

### 2.3. Главный коммерческий узел

| Параметр | Значение |
| --- | --- |
| Главное обещание | бесплатно подбираем новостройки и дома по военной ипотеке под задачу клиента |
| Primary CTA | `Получить подборку` |
| Secondary CTA | `Рассчитать ипотеку` → `/kalkulyator-voennoy-ipoteki/` |

## 5. Блок 01. Hero

### 5.1. Композиция

Две колонки на desktop (7/5), вертикальный stack на mobile. Фон `bg-primary` с grid pattern и radial gradient.

### 5.2. Левая плита

- **Eyebrow:** `Военный навигатор · бесплатно для военнослужащих`
- **H1:**
  ```
  Подбираем новостройки
  по военной ипотеке бесплатно
  ```
  Первая строка — базовый чёрный заголовок, вторая — с акцентом `по военной ипотеке`.
- **Lead:** `Проверяем одобрение банков, ликвидность и сроки сдачи до первого просмотра.`
- **Primary CTA:** `Получить подборку`
- **CTA поведение:** открывает modal с оффером `Получить разбор ситуации`
- **Micro-trust-line:** `Бесплатно для военнослужащих · Работаем с 8 банками`

### 5.3. Правая featured-card

- Одно статичное фото новостройки / интерьера / фасада.
- Две плашки поверх фото:
  - `Бесплатно`
  - `Сопровождение сделки`

### 5.4. Нижние route-cards

4 карточки в ряд на desktop, 2×2 на tablet, 1 колонка на узком mobile.

| Карточка | Поведение | Визуал |
| --- | --- | --- |
| Новостройки | modal: `Подберём лучшие новостройки под военную ипотеку бесплатно` | фото краснодарского ЖК |
| Дома | modal: `Поможем подобрать дом под ваш сценарий покупки бесплатно` | `public/images/cottages-hero.jpg` |
| Вторичка | modal: `Поможем подобрать готовую квартиру на вторичном рынке бесплатно` | `public/images/secondary-hero.jpg` |
| Ипотека | modal: `Поможем с военной ипотекой бесплатно` | `public/images/mortgage-hero.webp` |

Каждая карточка: фото + kicker `Бесплатно для вас` + название + подзаголовок + стрелка. Hover: lift + zoom фото + стрелка вправо-вверх. Все 4 карточки открывают один и тот же modal-shell с разными продающими заголовками и подзаголовками под сценарий пользователя.

### 5.5. Визуальный стиль

- Фон: `bg-primary` `#F1F3F5`
- Карточки: `bg-surface` `#FFFFFF` с тонкой рамкой `color-border`
- Радиусы: 10–12px
- Типографика: Manrope, H1 с контрастом веса
- Декор: grid pattern + radial gradient
