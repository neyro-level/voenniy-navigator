Отдельный контур для журнала:

- `../JOURNAL_EDITORIAL_MAP.md`
- `journal/README.md`
- `journal/ARTICLE_*.md`

Правило для SEO-задач:

1. сначала читать `../SEO_PASSPORT_VOEN_NAVIGATOR.md`
2. потом `../SEO_INTERNAL_LINKING_MATRIX_2026-07-03.md`, если задача про маршруты и ссылки
3. потом `../JOURNAL_EDITORIAL_MAP.md`, если задача связана с журналом
4. затем уже открывать нужный brief страницы или статьи

Важно:

- журнал является частью общей SEO-системы проекта, а не отдельным контентным архивом;
- каждая сильная статья должна иметь понятную связь с commercial page;
- при изменении статьи нужно поддерживать в порядке не только сам материал, но и его `ARTICLE_*.md`, editorial map и перелинковку.
