## 9. Методологические чек-листы

### H2-BRIDGE

- Это не техническое название блока: **да**
- Понятна роль блока: **да**
- Есть напряжение / вопрос клиента: **да**
- Есть сильный вывод: **да**
- Есть отличие или механизм: **да**
- H2 ведёт к следующему смыслу: **да**
- H2 не повторяет соседние блоки: **да**

### FAQ-SAFE

- Вопрос звучит как реальный вопрос клиента: **да**
- Вопрос закрывает сомнение, риск или условие: **да**
- Ответ начинается с прямого ответа: **да**
- Ответ не превращается в рекламу: **да**
- Есть ограничение, если оно важно: **да**
- Нет неподтверждённых обещаний: **да**

### Risk Reversal

- Есть блок «Кому не подходит»: **да** (внутри Conditions)
- Ограничения называются честно: **да**
- Есть фильтр отсечения: **да**

### Дизайн-система

- Фон: `bg/primary` / `bg/surface` чередуются по секциям.
- Карточки: `bg/surface`, ghost border, radius-lg/xl.
- Типографика: H1 display, H2 36px, H3 22px, body 16px.
- Premium-слои: grid в Hero, tonal layering, accent lines, stroke-иконки.
- Нет чистого белого на фонах, нет #000000, нет тёплых оттенков.
- Mobile: секции стопкой, CTA full-width, таблица → карточки.
