## 1. Роль страницы

`/journal/` — evergreen SEO-раздел для ранних информационных интентов по военной ипотеке.

Задача журнала:

- закрыть вопросы до выбора объекта;
- перевести информационный трафик в расчёт и подбор;
- усилить экспертность бренда без превращения сайта в личный блог;
- связать статьи с коммерческими страницами: Краснодар, Крым, калькулятор, условия, семейная ипотека.

Автор материалов в frontmatter и schema: **Военный навигатор**.

Важно:

- журнал не считается отдельным независимым проектом;
- журнал — часть общей SEO-системы сайта;
- развитие `/journal/` всегда должно проверяться через `SEO_PASSPORT_VOEN_NAVIGATOR.md`, `JOURNAL_EDITORIAL_MAP.md` и `SEO_INTERNAL_LINKING_MATRIX_2026-07-03.md`.

## 2. Архитектура

### Тексты Hero (актуальны с 2026-07-06)

- **Eyebrow:** Журнал Военный навигатор  
- **H1:** Военная ипотека: от условий до квартиры  
- **Lead:** Разбираем условия, считаем бюджеты и проверяем объект — до похода в банк и на сделку.


Технический паттерн взят из проекта `Союз Ростов (AMS)` и адаптирован под дизайн-систему Военного навигатора.

Медиа-контракт:

- `cover` — путь к обложке статьи;
- `coverAlt` — осмысленный alt-текст;
- `coverPosition` — опциональный CSS `object-position` для портретов и кадров с людьми, чтобы лица не обрезались в карточках и hero статьи на laptop/mobile.

Маршруты:

- `/journal/`
- `/journal/2/`
- `/journal/[slug]/`
- `/journal/category/[category]/`

`/blog/` не создаётся. Канонический раздел только `/journal/`.

## 7. SEO-перелинковка v2

- Архив `/journal/` теперь работает не только как информационный хаб, но и как навигационный вход в money-layer: добавлен блок `Главные страницы по теме`.
- Карточки статей в архиве и рубриках показывают отдельный маршрут `Следующий шаг` в основную commercial page кластера, чтобы журнал не гонял трафик только внутри себя.
- Страницы рубрик получили рекомендованную commercial page:
  - `Краснодар` -> `/voennaya-ipoteka-krasnodar/`
  - `Крым` -> `/voennaya-ipoteka-krym/`
  - `Расчёт и сумма` -> `/kalkulyator-voennoy-ipoteki/`
  - `Банки и условия` -> `/usloviya-voennoy-ipoteki/`
  - `Семейная ипотека` -> `/semeynaya-voennaya-ipoteka/`
  - `Сделка и риски` -> future `/kvartiry-po-voennoy-ipoteke/` и secondary `/usloviya-voennoy-ipoteki/`
- Страница каждой статьи должна иметь 1 primary route в money page и может иметь 1 secondary route как следующий шаг по соседнему intent.
- `Popular` и related-блоки больше не считаются достаточной перелинковкой сами по себе: рядом с article-to-article маршрутом должен быть article-to-commercial маршрут.
- Источник правды по архитектуре links: `project-docs/SEO_INTERNAL_LINKING_MATRIX_2026-07-03.md`.

## 8. Документация развития журнала

Журнал теперь имеет отдельный рабочий слой документации:

- `project-docs/JOURNAL_EDITORIAL_MAP.md` — master-файл по всему журналу, правилам написания, приоритетам и article map;
- `project-docs/briefs/journal/README.md` — вход в папку брифов;
- `project-docs/briefs/journal/ARTICLE_*.md` — отдельные брифы на каждую опубликованную статью.

Это и есть основной контур для дальнейшего усиления журнала, работы с ИИ и редакторской доработки материалов по одному.
