# Мониторинг ЖК для страницы `/voennaya-ipoteka-krym/`

**Проект:** Военный навигатор  
**Страница:** `/voennaya-ipoteka-krym/`  
**Дата мониторинга:** 2026-06-18  
**Задача:** собрать shortlist жилых комплексов для направлений `Симферополь / Севастополь / Побережье`, с приоритетом на ГК `ИнтерСтрой`, и разложить данные под текущий каталог страницы.

## Что нужно каталогу сейчас

Текущий data-layer каталога Крыма должен в итоге заполнить те же поля, что и тип `Complex`:

| Поле | Обязательно | Где используется сейчас | Комментарий |
| --- | --- | --- | --- |
| `id` | да | data-layer / key / modal source | Нужен короткий slug латиницей |
| `name` | да | карточка / карта | Публичное название ЖК |
| `developer` | да | карточка details | Для Крыма приоритетно `ИнтерСтрой` |
| `district` | да | карточка details / карта | Короткая человеко-понятная локация |
| `address` | да | карточка / карта | Лучше в формате улица + населённый пункт |
| `coordinates` | да | карта | Точные координаты нужно дособрать после утверждения shortlist |
| `class` | да | type compatibility | Комфорт / бизнес / комфорт+ |
| `deadline` | да | карточка | Человеческая строка: `2 кв. 2026`, `Сдан`, `4 кв. 2027, есть сданные` |
| `deadlineMin` | да | type compatibility | Год минимального срока |
| `deadlineMax` | да | type compatibility | Год максимального срока |
| `hasReady` | да | badge `Есть сданные` / `Новый этап` | Выводим из `Сдан` / `есть сданные` |
| `rooms` | да | карточка features | Набор: `studio`, `1`, `2`, `3`, `4` |
| `areaMin` | да | карточка features | Минимальная площадь |
| `areaMax` | да | карточка features | Максимальная площадь |
| `priceMin` | да | карточка title line | Минимальная цена входа |
| `pricePerMeterMin` | желательно | type compatibility | Можно добить отдельным проходом после утверждения |
| `images` | да | слайдер карточки | Понадобятся 3 реальных фото на каждый ЖК, это отдельный asset-pass |

## Как я проверял

| Слой | Как использовался |
| --- | --- |
| Яндекс.Недвижимость | основной структурированный источник: название, адрес, класс, срок сдачи, площадь, минимальная цена, ипотечный сигнал |
| ЦИАН | перекрёстная проверка по части ЖК, особенно когда нужен был дополнительный сигнал по типу помещений или диапазону площадей |
| Официальный сайт ИнтерСтрой | подтверждение географии проектов, принадлежности застройщику и отдельных диапазонов планировок |

## Важная оговорка перед утверждением

| Ситуация | Что это значит для страницы |
| --- | --- |
| Яндекс показывает `Льготная ипотека: семейная, военная, IT` | Это хороший сигнал для shortlist, но не всегда означает одинаково чистый сценарий для контентной витрины |
| На части объектов встречается слово `апартаменты` | Такие объекты не стоит ставить в основной пул без отдельного ручного подтверждения от отдела продаж |
| У ряда готовых севастопольских ЖК ИнтерСтрой нет чистого текущего прайса от застройщика в выдаче | Их лучше держать как reserve, а не как первый экран каталога |
