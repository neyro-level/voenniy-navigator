## 2. На чем строится продвижение

SEO-рост проекта строится вокруг узкой и точной темы:

- военная ипотека;

- Краснодар;

Это важно, потому что сайт не должен конкурировать по слишком широким и дорогим запросам вроде `новостройки Краснодара` как по основному направлению.

Наша стратегия на старте:

- занять понятную нишу по военной ипотеке;
- усилить уже созданные страницы;
- закрыть самые важные пробелы в структуре;

- затем постепенно расширять охват через журнал и новые SEO-страницы.

## 6. Роль журнала

Журнал в этой стратегии — не просто блог.  
Это отдельный SEO-кластер, который помогает продвигать коммерческие страницы.

Что делает журнал:

- собирает информационный спрос;
- отвечает на вопросы клиента до заявки;
- усиливает доверие к проекту;
- расширяет охват по длинным запросам;
- перелинковывает пользователя в коммерческие страницы.

На старте журнал уже выполняет важную функцию:

- поддерживает Краснодар;
- поддерживает Крым;
- поддерживает калькулятор;
- поддерживает условия;
- поддерживает семейный сценарий.

Это особенно важно в первые месяцы, когда сайту нужно быстрее получить тематическую полноту и лучше индексироваться.

Отдельно важно:

- журнал не дублирует коммерческие страницы;
- статьи закрывают supporting-интенты: документы, расчёт, риски, сравнения, гео-сценарии;
- внутренняя перелинковка уже собрана как часть SEO-системы.
